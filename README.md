# 晴訊 SkySignal · 網頁版

適合手機與電腦的繁體中文天氣網站，從晴訊 Android 0.50 的模型地圖延伸製作。使用 GitHub Pages 靜態託管，不需要伺服器金鑰，也不需要登入。

## 已提供的功能

- 當前模型天氣估算、逐小時及每日預報；五個全球模型 IFS／GFS／ICON／GEM／AIFS。
- 大型互動地圖：氣溫、風速與風向、降水、陣風、雲量、濕度、降雪、海平面氣壓；72 小時播放、風向流線及不同累積時段。
- 全球城市搜尋、使用目前位置、12 個收藏地點及瀏覽器本機偏好。
- 香港天文台及美國 NWS 官方警告。其他地區提供當地官方網站入口，明示尚未接入，不會把缺少警告資料顯示成「沒有警告」。
- 系統／淺色／深色外觀、km/h／m/s／蒲福風級、加入主畫面及離線介面。

## 與 Android 版的差異

這是可獨立運作的網頁版，並非在瀏覽器執行 Android APK。瀏覽器關閉後不會持續背景定位、監測警告或推送通知。收藏只儲存在目前瀏覽器，不會與 Android 版或其他裝置同步。

所有全球即時數值均為模型估算，已在介面標示，並非氣象測站觀測。各模型預報長度以來源實際提供的有效資料為準（例如 ICON 可能只提供七天有效的每日預報）。來源缺值保持留空。

## HTTP 400 與地圖修正

原始地圖對 81 個座標只附一個 `elevation=nan`，Open-Meteo 會拒絕整個請求。網頁版保留 0.50 修正：每個座標各附一個海拔設定，並依地圖實際大小設定氣象畫布寬高。模型地圖使用 9×9 區域取樣與內插，放大不會提高原始模型解析度。

地圖保留本機每分鐘／每小時／每天的取樣請求預算；時間播放及已下載圖層之間切換不重複下載。來源另有自身的流量限制。

## 開發與檢查

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run check
npm test
```

`public/` 是完整的靜態網站，可用任何支援 HTTPS 的靜態主機。所有內部資源使用相對路徑，支援 GitHub Pages 的專案子目錄。修改 `main` 後，GitHub Actions 會先檢查及測試，再部署 `public/`。

服務工作者只快取網站介面，不攔截外部氣象資料。上次成功的所選地點預報會儲存在本機，失敗或過期時顯示來源時間與狀態。發佈修改時應同步更新 `public/sw.js` 的快取版本。
